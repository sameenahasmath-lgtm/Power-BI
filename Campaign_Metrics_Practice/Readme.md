
# Campaign Metrics Project

This project analyzes a sample digital advertising campaign using key performance metrics such as CTR, CPC, CPM, Conversions, and CPA. The goal is to demonstrate pattern recognition, performance diagnosis, and insight generation — skills required for a Client Success Executive role.

## Metrics Included
- Impressions
- Clicks
- CTR (Click-Through Rate)
- CPC (Cost per Click)
- CPM (Cost per 1000 Impressions)
- Conversions
- CPA (Cost per Acquisition)

## What This Project Shows
- Ability to calculate and interpret core campaign metrics
- Pattern recognition across weekly performance
- Root cause thinking behind metric changes
- Clear communication of insights
- Dashboard interpretation (Power BI)

## Files in This Project
- `sample_campaign_data.csv` — sample dataset
- `Insights_Summary.md` — analysis + insights
- `Dashboard_Screenshot.png` — Power BI dashboard view

## Tools Used
- Excel / CSV
- Power BI (for visualization)
- Markdown (for documentation)
